# Plan: Fix English Translations for Both Local & Vercel

## Problem

The `/api/generate` endpoint (used by the UI's Generate button) produces flashcards with:
- `meaning`: Japanese context snippet (not English)
- `reading`: always empty
- `part_of_speech`: always "unknown"
- `jlpt_level`: always "N/A"

This affects both local development and Vercel deployment.

## Root Cause

`api/generate.js` uses regex tokenization only — no LLM, no dictionary, no translation capability.

## Solution

Add a JLPT vocabulary dictionary module that maps Japanese words → English meanings, hiragana readings, part of speech, and JLPT levels. This works everywhere (local + Vercel) with zero external API dependencies.

---

## Changes

### 1. Create `lib/vocabulary-dict.js` — JLPT Vocabulary Dictionary

A JSON-lookup module with ~600+ common JLPT N5/N4/N3 words:

```js
module.exports = {
  '今日': { reading: 'きょう', meaning: 'today', pos: 'noun', level: 'N5' },
  '明日': { reading: 'あした', meaning: 'tomorrow', pos: 'noun', level: 'N5' },
  // ... hundreds more
};
```

Coverage targets:
- **N5**: ~300 words (all essential vocabulary)
- **N4**: ~200 words (high-frequency only)
- **N3**: ~100 words (high-frequency only)

Each entry: `{ reading, meaning, pos, level }`

### 2. Update `api/generate.js` — Use Dictionary in `buildDeck()`

In the `buildDeck()` function, look up each extracted word in the dictionary:

```js
const dict = require('../lib/vocabulary-dict');

// In buildDeck():
const entry = dict[word];
cards.push({
  front: word,
  back: {
    reading: entry ? entry.reading : '',
    meaning: entry ? entry.meaning : info.first_ctx.slice(0, 50),
    part_of_speech: entry ? entry.pos : 'unknown',
    jlpt_level: entry ? entry.level : 'N/A',
    occurrence_count: info.count,
  },
  jlpt_level: entry ? entry.level : 'N/A',
});
```

Also update JLPT breakdown to count actual levels instead of all N/A.

### 3. Create `server.js` — Local Express Server

A simple Express server that:
- Serves `ui/` as static files at `/`
- Mounts `api/generate.js` handler at `/api/generate`
- Listens on port 3000

```js
const express = require('express');
const generateHandler = require('./api/generate');
const app = express();

app.use(express.static('ui'));
app.get('/api/generate', generateHandler);

app.listen(3000, () => console.log('http://localhost:3000'));
```

### 4. Add `express` dependency

```bash
npm install express
```

### 5. Add npm script to `package.json`

```json
"scripts": {
  "start": "node server.js",
  "dev": "node server.js"
}
```
